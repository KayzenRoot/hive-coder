# Hive Coder

Hive Coder is an AI-native desktop coding and computer-use platform.

This repository is being bootstrapped under the governed engineering flow used by the HIVE project. Product implementation must not start until the initial Source Pack, GEF execution/review contracts, and checkpoint are approved.

Initial direction: a dedicated Hive product with its own UI and orchestration layer, using Open Interpreter and Cua as foundational runtime/computer-use technologies behind explicit adapters.
