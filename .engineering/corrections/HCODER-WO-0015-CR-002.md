# HCODER-WO-0015-CR-002 — Deterministic Tauri icon and lock bootstrap

**Severity:** MEDIUM  
**Status:** RESOLVED IN CANDIDATE  
**Work Order:** `HCODER-WO-0015`

## Finding
The initial Windows candidate reached `tauri-build` but failed because the required Windows icon resource did not exist. At the same stage, npm/Cargo dependency locks were being resolved during bootstrap rather than already tracked as immutable review inputs.

## Correction
- Added deterministic pure-Python Hive icon generation and a `pretauri` hook so the requirement is reproducible outside CI as well as inside it.
- Reused the lock artifact generated by the reviewed Windows run, materializing only `package-lock.json` and `Cargo.lock` through a one-time restricted bootstrap path.
- Removed the temporary write-capable bootstrap workflow immediately after the locks were committed.
- Hardened CI to require committed lockfiles, `npm ci`, `cargo test --locked` and `cargo check --locked`.
- Security gate verifies root dependency parity and lockfile presence/version.

The final exact-head candidate builds the Tauri release executable and passes launch smoke using the committed lock graph.
