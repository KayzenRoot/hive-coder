# License & Provenance — Hive Coder

Third-party foundations must be evaluated before source import or distribution.

## Current candidates
- Open Interpreter: preferred runtime foundation candidate; exact repository/version/license obligations must be verified at the integration Work Order.
- Cua: preferred computer-use foundation candidate; exact repository/version/license obligations and optional dependency licenses must be verified at integration.

## Rules
Preserve required copyright/NOTICE/attribution; record source URL/version/commit and license for imported code; distinguish dependency use from copied/modified source; do not copy proprietary visual assets; scan transitive/optional dependencies before release; unresolved or incompatible licensing blocks distribution.

No final Hive Coder project license is selected by this bootstrap. A later governed decision must choose it after the dependency/provenance assessment.
