# Project Overview — Hive Coder

Hive Coder is a dedicated AI-native desktop coding and computer-use product. It is separate from the existing `hive-code` repository.

Initial product direction: a polished proprietary Hive UX/orchestration layer over explicit adapters for an Open Interpreter-derived execution runtime and Cua-derived computer-use capabilities, with OpenCode Go support as an important model/provider path.

The product should combine coding, shell/files, browser/computer control, visual validation, Git/PR workflow and governed autonomous execution while remaining replaceable at subsystem boundaries.
